# 🏠 House Price Prediction System

A Machine Learning regression project that predicts house prices based on property features using multiple regression algorithms.

### 🛠️ Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

### 🤖 Models Implemented
- Dummy Regressor
- Linear Regression
- Ridge Regression
- Lasso Regression

### ⚙️ Workflow
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Preprocessing
- Model Training & Evaluation

### 📊 Evaluation Metrics
MAE, MSE, RMSE, R² Score.

### 📁 Project Files
- Jupyter Notebook: Complete implementation.
- CSV Dataset: Housing data used for training and evaluation.

**Project Type:** Machine Learning | Regression | Capstone
